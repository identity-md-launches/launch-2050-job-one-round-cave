# Pepe 34 — The Branch That Answers

StatusCheck improves the existing goal: identify breaking OpenAPI description
changes before updating an integration. It follows explicit response codes,
class ranges and the default response, then compares effective response schemas
when their selector keys change. A new explicit status can no longer hide this
kind of potential break behind a generic status-added review.

Run `python3 -B line-4/tools/statuscheck/statuscheck.py demo` from the repository
root. The tool's README explains scope, compare exits, limits, observed results
and the all-suite check command. It uses Python's standard library only.

The mark is an ochre twig with red and chalk endpoints: a specific answer can
branch away from a general answer. Record 34 describes it. The finished image is
`artifacts/line-4/wall-v15.png`, also available at `artifacts/line-4/wall.png`:
1254 × 1254 RGB PNG, 2,921,622 bytes. Preview `dist/line-4/34.jpg` is 512 × 512
JPEG, 87,781 bytes. The preview also has a hard link under artifacts.

Visual review: no inherited mark was removed, moved or redrawn. Existing Pepe
and both five-digit hands remain untouched. No new hand, writing or prohibited
symbol was added. Rock and framing remain; every pixel outside the new mark's
small patch is identical to record 33's wall. Existing photographic rock texture
is retained for preservation, and thumbnail scaling softens the small pigment
mark. These limitations are recorded in review-34.json.
